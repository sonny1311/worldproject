# WORLD ENGINE

# DESIGN RULES

Version 1.0

--------------------------------------------

# 1

Der Spieler ist Unternehmer.

Nicht Angestellter.

Nicht Lagerarbeiter.

Nicht Kassierer.

Nicht Fahrer.

Nicht Buchhalter.

Die KI übernimmt Routinearbeiten.

Der Spieler trifft Entscheidungen.

--------------------------------------------

# 2

Jeder unnötige Klick ist schlecht.

Wenn etwas automatisch erledigt werden kann,
soll es automatisch erledigt werden.

Immer mit der Möglichkeit,
die Entscheidung zu ändern.

--------------------------------------------

# 3

Einsteiger müssen das Spiel verstehen.

Profis müssen Jahre später
noch Neues entdecken.

--------------------------------------------

# 4

Alles muss logisch sein.

Wenn etwas in der echten Welt
nicht funktionieren würde,

muss es einen guten Grund geben,
warum es im Spiel funktioniert.

--------------------------------------------

# 5

Jede neue Funktion beantwortet
eine Frage.

"Erhöht sie den Spielspaß?"

Wenn nein,

kommt sie nicht ins Spiel.

--------------------------------------------

# 6

Die Welt lebt.

Auch ohne den Spieler.

Firmen handeln.

Menschen kaufen ein.

Autos fahren.

Preise verändern sich.

Firmen gehen pleite.

Neue Firmen entstehen.

--------------------------------------------

# 7

Keine Magie.

Jeder Erfolg braucht einen Grund.

Mehr Kunden entstehen nicht zufällig.

Sondern weil:

- bessere Lage
- bessere Werbung
- bessere Preise
- besserer Ruf
- bessere Produkte

--------------------------------------------

# 8

Die KI ist ein Assistent.

Sie entscheidet niemals
gegen den Spieler.

Sie schlägt vor.

Der Spieler entscheidet.

--------------------------------------------

# 9

Alles muss skalieren.

Vom Dorf

↓

zur Kleinstadt

↓

zur Großstadt

↓

zum Land

↓

zur ganzen Welt.

--------------------------------------------

# 10

Keine Sackgassen.

Jedes System muss später
erweitert werden können.

--------------------------------------------

# 11

Performance ist wichtiger
als perfekte Grafik.

100 FPS

ist wichtiger

als perfekte Schatten.

--------------------------------------------

# 12

Simulation vor Animation.

Erst muss etwas funktionieren.

Danach wird es schön.

--------------------------------------------

# 13

Alle Daten liegen außerhalb
des Codes.

Produkte

Gebäude

Rezepte

Technologien

Fahrzeuge

alles datengetrieben.

--------------------------------------------

# 14

Keine Marken verwenden.

Alle Unternehmen,

Produkte,

Logos,

Namen,

Getränke,

Supermärkte,

Banken,

Hotels

werden fiktiv erstellt.

--------------------------------------------

# 15

Jeder Spieler baut
seine eigene Geschichte.

Es gibt keinen
richtigen Weg.

Nur Entscheidungen
mit Konsequenzen.

--------------------------------------------

# 16

Die Welt soll glaubwürdig sein.

Nicht kompliziert.

Nicht langweilig.

Glaubwürdig.

--------------------------------------------

# 17

Die Engine ist wichtiger
als das Spiel.

Ein gutes Fundament
hält Jahrzehnte.

--------------------------------------------

# 18

Jede Klasse hat
nur eine Aufgabe.

Keine Monsterklassen.

--------------------------------------------

# 19

Alles wird objektorientiert.

Keine globalen Daten.

--------------------------------------------

# 20

World Engine

ist kein Spiel.

World Engine

ist eine lebendige Welt.
