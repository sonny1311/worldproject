# ORVUNO – Google Play Update 1.0.1

- Version name: `1.0.1`
- Version code: `2`
- Kanal: Geschlossener Test

## Sichtbare Änderung

Die mobile Schnellnavigation am unteren Bildschirmrand wurde verbessert:

- Buttons reagieren beim Antippen jetzt deutlicher.
- Fokus/aktive Auswahl wird mit einer goldenen Kontur hervorgehoben.
- Horizontales Wischen durch die Navigation rastet sauberer an den Buttons ein.
- Das Scrollverhalten der unteren Leiste wurde für Smartphones stabilisiert.

## Vorschlag für die Google-Play-Versionshinweise

> Verbesserte mobile Navigation und Bedienbarkeit. Kleine Optimierungen für eine angenehmere Nutzung auf Smartphones.

## Build

Für Google Play muss das neue Android App Bundle mit demselben Upload-Key wie die erste Version signiert werden. Der nächste Build verwendet Version Code `2`.
